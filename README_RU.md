# Генератор самоподписных сертификатов и ключей для https

> [English version](README.md)

> [China version](README_CN.md)

Утилита `mini-cert` написанная C/CPP генерирует самоподписанный сертификат X.509 и закрытый RSA-ключ 2048 бит с возможностью добавления CertSubject (аналог команды `openssl req -x509 -nodes -newkey rsa:2048 -sha256`).

## Особенности

- **Генерация сертификатов** - самоподписанные сертификаты X.509 (DER/PEM)
- **Автономность** - не требует сторонних библиотек
- **Маленький размер** - оптимизированный код, размер бинарного файла минимален
- **Кроссплатформенность** - Windows (MinGW/GCC) и Unix-подобные системы

## Используемые модули

Утилита построена на сетевом стеке [crypery](crypery/README_RU.md) - реализации на чистом C без внешних криптографических зависимостей. В сборку входят четыре модуля:

- **tls** - базовый криптографический слой: TLS 1.2/1.3, AES-128-GCM, SHA-256, HMAC/HKDF, RSA-2048, ECDH (P-256, X25519), генерация и разбор самоподписанных X.509-сертификатов (DER/PEM). Именно этот модуль используется `mini-cert` для генерации ключа и сертификата.
- **ssl** - OpenSSL-совместимый API-слой над встроенной реализацией TLS: загрузка сертификата и ключа из PEM, рукопожатие, шифрованный ввод-вывод.
- **http** - HTTP/1.1-сервер: маршрутизация, раздача статики, WebSocket, SSE, gzip-сжатие (отключено флагом `HTTP_NO_GZIP`).
- **url** - HTTP/HTTPS-клиент: разбор URL, выполнение запросов, обработка редиректов, multipart/form-data.

## Параметры

Обязательные параметры:

| Параметр | Описание |
|----------|-----------|
| `-keyout <файл>` | Файл для записи закрытого RSA-ключа (например `private.key`) |
| `-out <файл>` | Файл для записи сертификата (например `certificate.crt`) |

Необязательные параметры:

| Параметр | Описание |
|----------|-----------|
| `-subj "<subject>"` | Subject в формате OpenSSL: `/C=RU/ST=Moscow/L=Moscow/O=MyCompany/CN=localhost`. Поля: `C`, `ST`, `L`, `O`, `OU`, `CN` (разделитель `/`). Если не указан, используется default `CN=ftps server` |
| `-days <n>` | Срок действия сертификата в днях (по умолчанию 365) |
| `-h`, `-help` | Показать справку |

Если обязательные параметры не заданы или заданы неверно, утилита выводит в консоль сообщение об ошибке и краткую справку.

Справка:

```bash
./mini-cert -help
```

## Результат

- `private.key` - закрытый RSA-ключ в формате PEM (PKCS#1 RSAPrivateKey)
- `certificate.crt` - самоподписанный сертификат X.509 в формате PEM

## Сборка

Сборка выполняется скриптом `build_gen.bat` (требуется GCC/MinGW):

```bat
build_gen.bat
```

Скрипт компилирует все модули crypery и `mini-cert.c` в один исполняемый файл:

```bat
gcc -O2 -o mini-cert.exe -I. -I./crypery./crypery/*.c mini-cert.c -DHTTP_NO_GZIP -lws2_32
```

## Использование

Готовый пример - скрипт `test_cert.bat`, создающий сертификат на 10 лет (3650 дней) для `localhost`:

```bat
test_cert.bat
```

Эквивалентная команда:

```bat
mini-cert.exe -days 3650 -keyout localhost.key -out localhost.crt -subj "/C=US/ST=New York/L=New York/O=MyCompany/CN=localhost"
```

Результат: файлы `localhost.key` (закрытый ключ) и `localhost.crt` (сертификат).
